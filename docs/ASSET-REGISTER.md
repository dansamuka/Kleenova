# Asset Register

| `assets/icons/favicon.svg` | Purpose-built vector mark for this project | SVG | Browser/site icon |

## AI hero art direction

The production prompt requested a bright, upscale modern interior with natural light, generous negative space for web copy, professional teal cleaning equipment, warm wood/greenery, no people, and no text/logos in the generated scene.

This avoids a common quality issue in AI web assets: unreliable embedded typography. All brand text remains real HTML or a source brand asset.

## Replacement policy

When high-quality real photography is available, retain this file naming/size strategy but replace the synthetic hero with an approved real image. Keep the original source image outside the published site if it contains metadata or customer-identifying details.
